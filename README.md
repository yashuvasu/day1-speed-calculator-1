# 🚗 Day 1 - Speed Calculator (C Language)

## 📌 Concept
Speed = Distance / Time

## 💡 Features
- Takes distance (km)
- Takes time (hours)
- Calculates speed (km/h)
- Converts to m/s

## 🛠️ Tech Used
- C Programming
- GCC Compiler

## 🚀 Output
Example:
Speed = 50 km/h
Speed = 13.89 m/s
